# Dashboard upgrade provenance

The dashboard upgrade takes product-level inspiration from
[auuuu4/notion-2api-web](https://github.com/auuuu4/notion-2api-web/tree/ed467fcc9ecf6d0d8b56dcf729e626227fbee675)
at commit `ed467fcc9ecf6d0d8b56dcf729e626227fbee675`.

Its LICENSE is Apache-2.0, despite its README saying MIT. No source code,
stylesheets, images or other assets from that project are copied by this
upgrade. The implementation uses this repository's existing Go/React code.

commercial-use permission is asserted.
